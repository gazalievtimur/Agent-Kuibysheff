# Студия

`kbshff-studio` открывает страницу того же профиля, что правит `config`, и запускает один пробный прогон. Сохранение пишет файлы в `.kuibysheff/protected/agents/<id>`. Следующий `kbshff run` читает их без отдельного экспорта.

Страница принимает только локальную петлю: `http://127.0.0.1:8790/`.

```powershell
kbshff-studio --project-root .
```

Без флагов берётся текущий каталог и открывается браузер. `--no-open` браузер не открывает. Остановка — Ctrl+C.

Тот же запуск через `kbshff`, если `kbshff-studio` лежит рядом с `kbshff`, в `PATH` или в `KBSHFF_STUDIO`:

```powershell
kbshff ui --project-root . --open
```

`kbshff a2a` по умолчанию занимает порт 8787.

Сборка из исходников кладёт оба бинарника в `target\release`.

## Вкладки

Слева: список агентов, обновление, новый агент, импорт.

| Вкладка | Назначение |
| --- | --- |
| Configure | Модель, пределы, журналы, карточки MCP, доступ, стоимость, Event-MCP, поручение, правила, умения и `skill.md` выбранного умения. Save пишет файлы профиля |
| MCP | Опрос инструментов сохранённой настройки, вызов, удобный и сырой ответ |
| Check | Те же проверки, что `kbshff check` |
| Test run | Один пробный прогон на процесс студии: текст, файлы, рабочая папка, пределы, ход, JSON, хвосты журналов, файлы `homes/<агент>/out/` |

Сопутствующие файлы умения на Configure не правят. Их кладут командой `config … skill file` или импортом.

Опрос MCP читает уже сохранённый `agent-config.yaml`. Сначала сохраните Configure. Зелёная отметка значит, что вызов студии прошёл. Ошибка внутри ответа инструмента подсвечивается в удобном виде.

Ключ модели с Configure пишется в `.env` профиля и на страницу не возвращается. Секреты MCP в переменных и заголовках видны как отметка «задан». Повторное сохранение с этой отметкой оставляет хранимое значение.

Кнопка **Продолжить** на Test run подхватывает сохранённый диалог.

## Сборка интерфейса

Отладочная сборка отдаёт HTML, CSS и JS из `ui/studio`. Обновление страницы показывает правку вёрстки. Код сервера остаётся в запущенном `kbshff-studio`. После новой ручки или флага бинарник пересобирают и перезапускают. Признак старого сервера: вкладка есть, а запрос MCP отвечает 404.

Релизная сборка вшивает страницу в `kbshff-studio`. `kbshff` страницу не содержит.

См. [docs/UI.md](../UI.md).

## VS Code

Расширение показывает агентов проекта, заполняет настройки и регистрирует их в канале редактора. Переписка остаётся чатом VS Code. Версия в `extensions/vscode/package.json` не связана с версией `kbshff`.

См. [extensions/vscode/README.md](../../extensions/vscode/README.md).
