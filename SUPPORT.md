# Support

## How to get help

- **Bugs and feature requests:** GitHub Issues  
  https://github.com/gazalievtimur/Agent-Kuibysheff/issues
- **Security vulnerabilities:** [SECURITY.md](SECURITY.md) only (private
  reporting). Do not file public issues with exploit details.
- **Contributing / development setup:** [CONTRIBUTING.md](CONTRIBUTING.md)

Support is **best-effort** from maintainers and volunteers. There is **no SLA**.

## Suggested issue labels

| Label | Use |
| --- | --- |
| `bug` | Incorrect behavior or crash |
| `enhancement` | Feature request |
| `security` | Security-sensitive discussion (still use private reporting for vulns) |
| `docs` | Documentation |
| `ci` | CI / release automation |

## Out of scope

- Private consulting or guaranteed response times
- Support for unsupported platforms (macOS, Linux aarch64) unless explicitly
  documented later
